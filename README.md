# LD Portfolio

Личный сайт-портфолио с интеграцией Discord, Modrinth и GitHub.

## Возможности

- 🌐 Двуязычный интерфейс (RU/EN)
- 🟢 Реальный статус Discord через Lanyard API
- 📦 Автоматическая загрузка проектов с Modrinth и GitHub
- 💬 Кастомный Discord виджет
- 🎨 Современный дизайн с анимациями

## Технологии

- Vanilla JavaScript
- CSS3 с кастомными свойствами
- Discord Widget API
- Modrinth API
- GitHub API
- Lanyard API

## Запуск локально

Просто открой `index.html` в браузере.

## Деплой

Сайт автоматически публикуется через GitHub Pages.
